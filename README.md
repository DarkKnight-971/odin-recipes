# odin-recipes

This repository is meant for practicing the practical stuff I have covered so far in the **Odin Project | Foundation course**.

### Topics so far:

- Terminal
- Git
- HTML

### Pre-requisites:

- Clone this repository using:

```bash
  git clone https://github.com/DarkKnight-971/odin-recipes
```

- Check the status to make sure the repository was properly cloned:

```bash
  cd odin-recipes/
  ls
```

- If cloning using SSH, verify your account before using:

```bash
  ssh -T git@your-github-username
```
